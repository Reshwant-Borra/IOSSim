# Apple GPX Core Location Control

This directory contains a physical-device XCTest control for measuring Core Location output from Apple's own Xcode GPX replay path.

## Fixture

`Fixtures/apple-gpx-35mph.gpx` was generated by `Fixtures/generate_apple_gpx_35mph.swift`.

The generator uses:

- Origin: `37.33170000,-122.03070000`
- Speed: `15.646 m/s`
- Timestamp spacing: `10 seconds`
- Distance per segment: `156.46 meters`
- Segment count: `16`
- Intended route duration: `160 seconds`
- Bearings: `90, 90, 90, 45, 45, 0, 0, 270, 270, 315, 315, 180, 180, 135, 135, 90`

Each waypoint has a monotonically increasing `<time>` value and an `<ele>` value. The timestamps encode the intended velocity: adjacent waypoint distance is approximately `156.46 m`, and adjacent timestamps are `10 s` apart.

## Output

The XCTest writes and attaches:

- `APPLE-GPX-<timestamp>.jsonl`
- `APPLE-GPX-<timestamp>-summary.txt`

The JSONL contains raw observations, adjacent-pair measurements, and a final summary record. The raw observation rows retain negative Core Location speed/course values and separately include normalized nullable values.

To retrieve the files from Xcode:

1. Run the `AppleLocationControl` scheme on a physical iPhone.
2. Open the Report navigator.
3. Select the completed `AppleGPXLocationControlTests/testAppleGPXJourneyCharacterization` run.
4. Open the test's Attachments section.
5. Export `APPLE-GPX-<timestamp>.jsonl` and `APPLE-GPX-<timestamp>-summary.txt`.
