# Apple Location Controls V2

This document records Apple first-party Core Location control experiments. These controls are isolated from IOSSim Drive: they do not call `LocationCoordinator`, DVT, `RPPairing`, `LocalDevVPN`, or `DriveScheduler`, and they do not set simulated locations from inside the app.

## Passive Recorder

UI path:

```text
Settings -> Developer -> Apple Location Controls
```

The screen is named `Passive Core Location Recorder`.

Controls:

- `Start Recording`
- `Stop Recording`
- `Export`
- `Copy JSONL`

Metadata labels:

- `REAL_DEVICE`
- `XCODE_DEBUG_GPX`
- `XCUILOCATION`
- `OTHER`

The label only changes output metadata. It does not change Core Location behavior.

Each run records every `CLLocationManager.didUpdateLocations` delegate callback and every `CLLocation` object in each callback. It retains raw negative `speed`, `course`, `speedAccuracy`, and `courseAccuracy` values and separately reports normalized validity.

Exports are written under the app Documents directory:

```text
AppleLocationControls/APPLE-<LABEL>-<UTC timestamp>.jsonl
AppleLocationControls/APPLE-<LABEL>-<UTC timestamp>-summary.txt
```

The app also exposes `Copy JSONL` so UI tests can attach the recorder output without relying on manual share-sheet interpretation.

## Xcode Debugger GPX Control

Apple documents GPX-based simulated location for Xcode tests, and Core Location documentation notes that software-simulated locations can be loaded with GPX files using the Xcode debugger. The repository includes a dedicated run scheme:

```text
AppleDebuggerGPXControl
```

That scheme launches the normal app target with location simulation enabled in the launch action. The canonical GPX fixture remains:

```text
ios/Tests/LocationControl/Fixtures/apple-gpx-35mph.gpx
```

The fixture was generated by:

```text
ios/Tests/LocationControl/Fixtures/generate_apple_gpx_35mph.swift
```

It encodes monotonically increasing waypoint timestamps for an intended route speed of approximately `15.646 m/s`.

Runbook:

1. Connect and unlock the iPhone.
2. Open `ios/IOSSimOnDevicePOC.xcodeproj`.
3. Select scheme `AppleDebuggerGPXControl`.
4. Select the physical iPhone destination.
5. Run the app under the debugger.
6. Open `Settings -> Developer -> Apple Location Controls`.
7. Set label `XCODE_DEBUG_GPX`.
8. Tap `Start Recording` and grant location permission if prompted.
9. In Xcode, use the debugger location simulation control, or `Debug -> Simulate Location`, and choose `apple-gpx-35mph.gpx`. If the GPX is not listed, add the GPX file to the project/workspace and select it from the same debugger location menu.
10. Let the route run for 2-3 minutes.
11. Tap `Stop Recording`.
12. Use `Export` or retrieve the files from the app Documents directory. Upload both JSONL and summary.

If Xcode ignores GPX timestamps and applies its own replay cadence, the recorder output will show that through callback intervals, `CLLocation.timestamp` intervals, geometric step distance, and geometric speed.

## XCUILocation Control

The local Xcode 26.5 headers expose:

```swift
XCUIDevice.shared.location = XCUILocation(location: CLLocation(...))
```

`XCUILocation` wraps a source `CLLocation`. The control constructs source `CLLocation` values with explicit latitude, longitude, altitude, horizontal accuracy, vertical accuracy, course, course accuracy, speed, speed accuracy, and timestamp. The experiment records what the app receives; it does not assume those properties survive the UI automation bridge.

Scheme:

```text
AppleXCUILocationControl
```

Target:

```text
IOSSimLocationControlUITests
```

Tests:

- `testOpenAppleLocationControlsSmoke`
- `testXCUILocationSinglePointMetadataControl`
- `testXCUILocationRouteControl`

Build:

```bash
xcodebuild \
  -project ios/IOSSimOnDevicePOC.xcodeproj \
  -scheme AppleXCUILocationControl \
  -configuration Debug \
  -sdk iphoneos \
  -destination 'generic/platform=iOS' \
  -allowProvisioningUpdates \
  build-for-testing
```

Physical single-point run:

```bash
xcodebuild \
  -project ios/IOSSimOnDevicePOC.xcodeproj \
  -scheme AppleXCUILocationControl \
  -configuration Debug \
  -destination 'platform=iOS,name=<YOUR IPHONE NAME>' \
  -allowProvisioningUpdates \
  test \
  -only-testing:IOSSimLocationControlUITests/AppleXCUILocationControlUITests/testXCUILocationSinglePointMetadataControl
```

Physical route run:

```bash
xcodebuild \
  -project ios/IOSSimOnDevicePOC.xcodeproj \
  -scheme AppleXCUILocationControl \
  -configuration Debug \
  -destination 'platform=iOS,name=<YOUR IPHONE NAME>' \
  -allowProvisioningUpdates \
  test \
  -only-testing:IOSSimLocationControlUITests/AppleXCUILocationControlUITests/testXCUILocationRouteControl
```

The UI tests attach copied JSONL as XCTest attachments when the app records observations.
