# Live Metrics

The dashboard labels host data precisely:

- Host-planned apparent speed.
- Host-calculated emitted apparent speed.
- Host-calculated average apparent speed.
- Planned and actual update interval.
- Timing drift and command latency.
- Emitted distance and estimated remaining distance.
- Successful and failed location writes.
- Device, tunnel, state, run, repeat, phase, sample, coordinate, and subprocess status.

Charts are lightweight SVG paths for speed, cumulative distance, drift, and latency. They do not represent iPhone sensor readings.
