# Interpretation

Allowed interpretation:

```text
The selected IOSSim profile was associated with a Trip observation under the recorded conditions.
```

Not supported:

```text
Life360 algorithm confirmed.
Drive threshold proven.
CLLocation speed successfully injected.
Motion successfully simulated.
```

Coordinate playback, physical phone state, permissions, network conditions, timing drift, and application processing delay can all differ between runs. An observed association does not identify causality.
