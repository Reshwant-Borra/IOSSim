# Recording Results

After a run, manually choose Drive observed, Trip observed, No event observed, Still processing, Application not checked, Inconclusive, Test failed, or Other.

Record check time, display values, permissions, battery/power state, connectivity, phone movement, screen/application state, passenger status, notes, and an optional screenshot filename. IOSSim stores only the filename; it does not capture a screenshot.

Data remains separated into IOSSim-generated facts, user-entered conditions, user-observed external result, and interpretation. Do not automate a third-party login, tap, screen capture, scrape, or private network inspection.
