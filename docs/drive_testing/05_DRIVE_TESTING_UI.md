# Drive Testing UI

The sidebar's dedicated **Drive Testing Lab / Experimental** button opens an overlay inside the existing map workspace. The visible map remains the current Leaflet map and shows the route, completed samples, remaining samples, and current emitted coordinate.

Tabs cover Device Check, Route Setup, Profiles, Live Test, Experiment Queue, Results, History, Comparison, and Help. Start remains disabled until flags, backend, device, tunnel, route, profile, and controller ownership checks pass.
